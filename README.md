**Course:** CIS 5300 / HW1

## Overview

Developed lexical-feature classifiers and compared length and frequency baselines with Naive Bayes, logistic regression, and gradient boosting. Examined errors and transfer to biomedical and news text.

## Guiding question

How well do lexical features identify complex words, and how does performance change across domains?
